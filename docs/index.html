sbox-rs

Экспериментальный порт s&box на Rust и wgpu: модель сцены, загрузчики форматов Source 2 и рендерер.

GitHub Статус Сборка

Скриншоты

Кадры отрисованы самим рендерером без захвата экрана: sbox-app --screenshot out.png. Ассеты игры в репозиторий не входят.

Проверка форматов на реальных файлах: контейнер 6878/6878, KV3 6999/7014 блоков, текстуры 2618/2618 (размеры мипов совпадают до байта), модели 743/744.

Важно: это не полный порт и не замена движка. Исходный s&box — около миллиона строк C# поверх закрытого ядра Source 2; здесь воспроизводятся форматы и базовый рантайм.

Сборка

git clone https://github.com/LakoMoor/sbox-rs
cd sbox-rs
cargo run -p sbox-app --release

Чтобы открыть реальную модель, нужны файлы игры. Склонируйте sbox-public, выполните там Setup.bat (скачает бинарники и ресурсы) и укажите путь:

cargo run -p sbox-app --release -- path/to/game/core/models/arrow.vmdl_c
Неофициальный проект, не связан с Facepunch Studios и Valve. s&box и Source 2 принадлежат их владельцам. Код sbox-rs — MIT.
